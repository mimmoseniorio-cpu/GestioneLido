# OmbrelloneOS

Gestionale per la gestione quotidiana degli ombrelloni di uno stabilimento
balneare. Sostituisce carta, Excel, telefonate e memoria del gestore.

**Stato: FASE 0 — documenti di progetto. Nessun codice ancora scritto.**

## Da dove si parte

| Se sei… | Leggi |
|---|---|
| un agente che riprende il lavoro | `STATUS.md` |
| chi deve capire cosa costruiamo | `PROJECT_BRIEF.md` |
| chi deve sapere come si lavora qui | `AGENT_PROTOCOL.md` |
| chi cerca perché è stato scelto X | `DECISIONS.md` |
| chi vuole avviare la prossima fase | `KICKOFF_PROMPT.md` |

## Principio guida

> Prima di implementare qualunque cosa: *questa funzione riduce i secondi che il
> gestore impiega a gestire un ombrellone?* Se no, non appartiene all'MVP.
